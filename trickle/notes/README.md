# StudentOS

A modern desktop interface for university students combining the elegant design of macOS with the colorful aesthetics of Windows XP. Built with React and TailwindCSS.

## Features

- **Desktop Environment**: Draggable windows with macOS-style titlebar controls
- **Dock Interface**: Bottom-centered dock with hover animations
- **Student Tools**: Dashboard, courses, grades, messages, and settings
- **AI Assistant**: Interactive chat with special genie lamp animation
- **Theme Support**: Toggle between light and dark modes
- **Glass Morphism**: Modern glassmorphic design with backdrop blur

## Quick Start

Simply open `index.html` in a modern web browser. No build tools or installation required.

## Components

- **Dashboard**: Overview of GPA, credits, courses, and upcoming deadlines
- **Courses**: View enrolled courses with progress tracking
- **Grades**: Academic performance breakdown with letter grades
- **Messages**: Communication hub for professors and study groups
- **Settings**: Customize appearance and notification preferences
- **AI Assistant**: Get help with studies through AI-powered chat

## Theme Variables

The app uses CSS custom properties for theming:
- Primary Color: Blue (#007AFF light / #0A84FF dark)
- Secondary Color: Cyan (#5AC8FA light / #64D2FF dark)
- Accent Color: Orange (#FF9500 light / #FF9F0A dark)

## Browser Support

Works best in modern browsers with CSS backdrop-filter support:
- Chrome 76+
- Safari 9+
- Edge 79+
- Firefox 103+
